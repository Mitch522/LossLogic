# LossLogic Project Brief

## Purpose

LossLogic is an independently developed insurance technology portfolio project demonstrating how complex bodily injury claim information can be transformed into structured data and evaluated through reproducible business logic.

The project uses entirely fictional and synthetic claim data.

## Business Problem

Bodily injury claim evaluation requires information from multiple sources to be reconciled before an adjuster can reach a defensible evaluation. Relevant considerations can include:

- coverage
- liability and comparative negligence
- accident mechanics
- medical chronology
- pre-loss medical history
- post-loss treatment
- medical causation
- billing activity
- duplicate and corrected charges
- procedure relationships
- PIP payments
- reasonable medical expenses
- remaining medical specials

LossLogic models these information sources separately and brings them together into a structured claim evaluation.

## Portfolio Goals

This project demonstrates:

- insurance domain expertise
- structured data modeling
- Python-based business logic
- multi-source evidence reconciliation
- medical chronology analysis
- billing reconciliation
- deterministic calculation and validation
- automated testing
- explainable claim evaluation
- AI-ready insurance workflow design

## Design Principles

1. All claim information is fictional and synthetic.
2. Source evidence remains separate from evaluation logic.
3. Conclusions should be traceable to underlying evidence.
4. Financial calculations should be reproducible.
5. Ambiguous evidence should be identified rather than silently resolved.
6. The system should produce both machine-readable output and a human-readable claim evaluation.
